# 射的（3D）

縁日の射的屋。コルク 10 発で、3 段の棚に並んだ景品を撃ち落とすゲーム。three.js r128（cdnjs）を使っています。

```
open games/shateki/index.html   # ブラウザで開くだけ（three.js は CDN から読み込み）
```

- マウスで狙ってクリック／スマホは指でなぞって離すと発射。矢印キー＋`Space` でも操作できる
- 照準は少しぶれる
- 景品は重さ `m` と奥行き `d` を持つ。当たった高さが `m × d` を超えると倒れて落ちる
- 超えないときは、当たるたびに少しずつ奥へずれる。棚の奥の端を越えると落ちる
- キャラメル 10 / ラムネ 20 / こけし 30 / だるま 50 / 招き猫 80 / ゲーム機の箱 150 点

`game.html` は Artifact 公開用。`index.html` は `games/wrap.sh games/shateki` で生成。
