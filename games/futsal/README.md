# 5対5 ナイトフットサル（3D）

自分で選手を操作する 5 人対 5 人のフットサル。three.js r128（cdnjs）で、テレビ中継風のカメラです。スマホの縦画面では、相手ゴールが上に来る視点に切り替わります。選手の能力は 3 分類 9 項目に絞っていて、操作していない 4 人と相手チームの動きは、すべてこの数値で決まります。

```
open games/futsal/index.html   # three.js は CDN から読み込み
```

| 分類 | 能力 | 試合での効き方 |
|---|---|---|
| フィジカル | キック | パス・シュートの速さ、ロブの高さ |
| | ジャンプ | 浮き球の競り合い（ヘディング）、GK の届く範囲 |
| | フィジカルコンタクト | タックル成功率、体がぶつかったときの押し合い・ショルダーチャージ |
| サッカーIQ | 立ち位置 | 陣形からのずれの少なさ、空いたスペースを探す精度、判断ミスの少なさ |
| | 積極性 | プレスの高さと人数、前へのパス、シュートを打つ距離 |
| | 消極性 | 守備時の撤退、ゾーン維持、バックパス・安全なパスの選びやすさ |
| タッチ | ドリブル | 持ったときの速さ、トラップ成功率、相手を抜く確率 |
| | ボディコンタクト | 体を入れてキープ、当たられてもボールを失いにくい |
| | 間合い | 寄せる距離の正確さ（近すぎると抜かれる）、かわす方向の判断 |

- チームはプリセット 5 種類から選ぶか、合計 50 ポイント（各 1〜10）を自分で振り分けます。3 分間の試合です
- 攻撃：`WASD`/矢印で移動、`Shift` でダッシュ（ボールが足から離れて奪われやすくなる）、`Z` でパス、`X` 長押しで溜めてシュート（溜めすぎると枠の上へ）、`C` でスルーパス、`V` でロブ
- 守備：`Z` で選手を切り替え、`X` を押している間は自動で寄せるプレス、`C` でタックル
- スマホ：画面左をなぞるとスティック、右下にシュート・パス・スルー・ダッシュのボタン
- 試合後に、保持率・シュート（枠内）・パス成功・奪取・空中戦の数字を表示します

`game.html` は Artifact 公開用。`index.html` は `games/wrap.sh games/futsal` で生成。
